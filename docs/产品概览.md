# 产品概览

## 产品定义

DnD Toolkit 是一款面向 Dungeons & Dragons 5E 2014 的跨端角色卡与跑团辅助应用。它让用户在 Windows 或 Android 上创建和维护角色卡，并在跑团过程中快速查看状态、消耗资源和进行骰子检定。

它是工具而不是规则裁判：应用负责存储用户输入、执行明确的数值计算和展示骰子结果，不替代 DM 对难度、成功、失败或叙事后果的判断。

## 目标用户

目标用户是任何需要编辑角色卡、查看角色状态和进行检定的人。玩家和 DM 在这些能力上的需求不作产品层面的区分，当前不建立不同身份、权限或工作流。

## 核心使用场景

### Windows：集中编辑

- 创建角色并填写基础资料、属性、熟练、战斗、人物设定和施法信息。
- 从项目专用中文 PDF 导入角色。
- 将角色重新导出为项目专用 PDF。
- 管理多个本地角色并手动备份到云端。

### Android：跑团中快捷操作

- 选择正在使用的角色。
- 查看生命值、护甲等级、先攻、速度、生命骰和法术。
- 快速调整当前生命值、临时生命值、钱币和剩余法术位。
- 进行属性检定、豁免、技能、先攻、死亡豁免、武器命中或自由掷骰。

两端当前提供相同功能，只是因屏幕、输入方式和使用环境不同而各有更适合的场景。

## 规则范围

- 当前规则基线：5E 2014。
- 已确认路线：增加对 5R（5E 2024）的兼容。
- 中文术语：以当前 UI 文本为准。
- 应用不内置职业、种族、背景、法术、专长或规则原文。
- 所有此类内容由用户自行输入，因此可以兼容第三方扩展和玩家自制内容。
- 属性修正、熟练加值和技能关联等明确计算可以由应用完成。

5R 兼容不能通过直接改变现有 5E 2014 行为实现。未来需要能够明确识别规则版本，并保证旧角色继续按原规则解释。

## 离线与联网原则

本地角色管理、PDF、冒险状态和掷骰均应离线可用。联网能力只有：

- 用户主动进入云端备份并上传、下载或刷新列表。
- 应用启动或用户手动触发的 GitHub Release 更新检查。
- 用户主动打开项目主页、发布页等外部链接。

网络失败不得阻止应用启动、读取本地角色或使用冒险功能。更新检查属于可选增强，不是核心依赖。

## 云端定位

Supabase 仅用于手动云端备份，不是传统账户系统、实时同步服务或多人协作后端。

- 用户通过本地保存的 UUID v4 身份令牌标识数据归属。
- 拥有令牌即拥有相应云端数据的访问能力。
- 令牌丢失无法通过邮箱、密码或客服流程恢复。
- 本地角色是主要副本，用户自行决定何时上传或下载。
- 出于成本考虑，云端不保存角色画像；这一限制预计长期存在。

## 产品边界

### 当前包含

- 多角色的创建、编辑、查看和删除。
- 专用中文角色卡 PDF 的导入和导出。
- 本地离线 JSON 持久化。
- 跑团状态快捷查看和编辑。
- 仅展示结果的骰子检定及会话内日志。
- 基于身份令牌的 Supabase 手动云备份。
- GitHub Release 新版本提示和下载跳转。
- 浅色/深色主题和 Windows/Android 响应式布局。

### 当前不包含

- 传统注册、登录、找回密码或账号恢复。
- 自动、后台或实时双向同步。
- 图片云备份。
- 云端角色删除入口。
- 多人房间、联机掷骰、DM 控制台或权限系统。
- 内置规则资料库或角色构筑内容库。
- 自动判断检定是否通过 DC。
- iOS、macOS、Linux 或 Web 正式支持。

## 成功标准

- 用户的数据升级后仍可读取，单个损坏文件不影响其他角色。
- 无网络时，除云备份和在线更新外功能保持可用。
- Windows 和 Android 使用同一领域模型，不产生平台专属数据分叉。
- 快捷状态修改不会被意外丢失。
- 掷骰的组成和加值对用户透明，结果不产生未经用户确认的状态变化。
- 后续 AI 能通过文档定位改动范围、识别兼容风险并执行对应验证。
