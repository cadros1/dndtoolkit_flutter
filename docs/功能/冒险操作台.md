# 冒险操作台

## 目标

冒险操作台面向跑团过程中的高频操作：快速选择角色、查看核心战斗值、调整消耗型状态并进行检定。它不是完整编辑器，复杂和长期资料应在角色编辑页维护。

## 入口和选择角色

- 一级导航“冒险”。
- 没有本地角色时提示先创建角色。
- 进入页面读取全部本地角色并默认选择列表第一项。
- 当前选择不会跨页面实例持久化。
- 切换角色前会触发当前角色保存，并把检定类型重置为自由检定、额外加值重置为 0。

## 状态概览

当前角色卡展示：

- 当前 HP、最大 HP、临时 HP 和组合生命条。
- 当前 HP 为 0 且最大 HP 大于 0 时显示的死亡豁免 Card。
- 当前/最大生命骰。
- AC、先攻、速度。
- 钱币入口。
- 法术与剩余法术位入口。
- 检定中心入口。

当前生命条使用已限制后的数值展示：当前 HP 位于 0～最大 HP，临时 HP 不低于 0。临时 HP 始终作为额外区段扩展总容量，因此不会填补已损失普通生命值对应的空缺。低生命值颜色只按“当前 HP / 最大 HP”判断。

## 状态修改

### HP

- 当前 HP 和临时 HP 支持加、减和直接输入；加减按钮在边界停用，直接输入在提交时修正。
- 当前 HP 下限为 0、上限为最大 HP；临时 HP 下限为 0且不设上限。
- 当前 HP 恢复为正数时清空死亡豁免进度；最大 HP 为 0 时不显示死亡豁免 Card。
- HP 改动主要在切换角色、离开页面、应用进入后台/非活动时保存。

### 生命骰

- 当前生命骰为自由文本，最大生命骰只读展示。
- 修改在页面生命周期保存点持久化。

### 钱币

- CP、SP、EP、GP、PP 均可增减或输入。
- 每次变化立即触发静默保存。
- 不自动换算币种，不阻止负数。

### 法术位

- 戏法只显示已配置法术，不显示法术位控制。
- 1～9 环显示 `remainSlots / totalSlots`。
- 剩余法术位只允许在 0 和总法术位之间增减。
- 每次变化立即触发静默保存。
- 法术名称与准备状态只读；编辑应在角色编辑页进行。

## 自动保存时机

`AdventurePage` 当前在以下时机保存选中角色：

- 钱币变化。
- 法术位变化。
- 死亡豁免投骰、手工调整、重置或自然 20 恢复生命值。
- 切换到另一个角色之前。
- 切换一级导航导致页面销毁。
- 应用进入 `paused` 或 `inactive`。

保存会更新 `updatedAt`，因此跑团状态变化也会影响云端冲突判断。

自动保存调用目前没有统一排队或防抖，并可能在页面销毁时异步进行。若修改该逻辑，应避免并发写入和最后写入覆盖新状态。

## 检定中心

- Android/窄屏：可拖动 bottom sheet，控制区与日志上下排列。
- Windows/宽屏：对话框，左侧控制、右侧日志。
- 检定类型分为属性/豁免、技能、其他、自由；死亡豁免不再出现在检定中心。
- 检定日志最近结果置顶，可在当前会话清空。
- 日志不保存到角色、文件或云端。

详细规则见 [掷骰检定](掷骰检定.md)。

## 死亡豁免

- 专用 Card 是应用内唯一的死亡豁免入口，只在最大 HP 大于 0且当前 HP 为 0时显示。
- 每次固定投一次普通 D20：10～19 记录一次成功，2～9 记录一次失败，自然 1 记录两次失败。
- 自然 20 恢复 1 点当前 HP、清空死亡豁免并隐藏 Card，同时给出提示。
- 三次成功显示“稳定”但不恢复 HP；三次失败显示“死亡”。终局后停止继续投骰，直到重置或手工撤回终局进度。
- 两侧圆点可以手工设置连续进度，用于实体骰、0 HP 受伤和纠错。重置只清空 Card 状态，不修改 HP 或检定日志。
- 最近一次骰面只在当前页面实例中展示；每次 Card 投骰仍进入会话日志。成功/失败进度使用角色现有字段并立即保存。

## 数据安全和边界

- 普通掷骰不会改变角色状态；专用死亡豁免会更新死亡豁免进度，自然 20 还会恢复 1 点当前 HP。
- 调整状态只影响当前选择的本地角色，不会自动上传云端。
- 关闭应用或发生崩溃前未命中保存时机，HP/生命骰可能丢失；钱币和法术位因即时保存风险较低。
- 下载云端角色时可能覆盖冒险页尚未保存的同 ID 状态；当前 UI 流程通常通过页面切换触发保存，但不应依赖隐含时序。

## 验收重点

- 切换角色不会把 A 的状态写到 B。
- 离开并重新进入冒险页后状态仍存在。
- 后台/锁屏后状态仍存在。
- 法术位不能低于 0 或高于总量。
- 当前 HP 不能低于 0 或高于最大 HP，临时 HP 不能低于 0。
- 死亡豁免 Card 显隐、自然 1/20、三次成功/失败、手工进度和重置均符合上述契约。
- 没有法术数据或旧版不完整 spellbook 时不崩溃。
- 检定日志不会进入 JSON 或触发云端更新。
