# 掷骰检定

## 产品语义

普通掷骰只计算并展示随机结果和加值组成。应用不接收 DC，不自动宣告成功或失败，也不修改角色字段。

冒险页的专用死亡豁免 Card 是明确例外：它按固定规则记录成功/失败，自然 20 会恢复 1 点当前 HP。该入口不属于通用检定中心。

自然 20/1 的颜色只是骰面提示，不代表所有检定在 5E 2014 中自动成功或失败。

## 检定类型

| 类型 | 骰子 | 基础加值 |
| --- | --- | --- |
| 属性检定 | 固定 D20 | 对应属性修正值 |
| 豁免检定 | 固定 D20 | 属性修正值 + 已熟练时的熟练加值 |
| 技能检定 | 固定 D20 | 关联属性修正值 + 已熟练时的熟练加值 |
| 先攻检定 | 固定 D20 | `combat.initiative` |
| 武器命中检定 | 固定 D20 | `weapon.attackBonus` |
| 自由检定 | D4/D6/D8/D10/D12/D20/D100 | 0 |

所有类型再加用户在检定中心设置的临时“额外加值”。额外加值只存在于当前页面实例，不写回角色。

## 专用死亡豁免

- 只在最大 HP 大于 0且当前 HP 为 0时显示，固定投一次普通 D20，不使用检定中心的优势、劣势、额外加值或多次投掷。
- 10～19 增加一次成功，2～9 增加一次失败，自然 1 增加两次失败，计数最多为三次。
- 三次成功后显示“稳定”并保留三次成功用于展示；三次失败后显示“死亡”。两种终局都会禁止继续投骰，直到重置或手工撤回进度。
- 自然 20 恢复 1 点当前 HP并清空进度。恢复正生命值会隐藏 Card，后续再次归零时从空白进度开始。
- Card 圆点允许手工调整连续进度；最近骰面和日志仅保留在当前页面会话，成功/失败进度进入角色 JSON。

## 技能映射

| 属性 | 代码 key |
| --- | --- |
| 力量 | `athletics` |
| 敏捷 | `acrobatics`, `sleightOfHand`, `stealth` |
| 智力 | `arcana`, `history`, `investigation`, `nature`, `religion` |
| 感知 | `animalHandling`, `insight`, `medicine`, `perception`, `survival` |
| 魅力 | `deception`, `intimidation`, `performance`, `persuasion` |

当前不支持专精双倍熟练、半熟练或用户为技能选择不同关联属性。

## 优势与劣势

控制为互斥三态：劣势、正常、优势。

- 正常：使用第一次骰值。
- 优势：掷两次同面骰，取较高值。
- 劣势：掷两次同面骰，取较低值。

由于 UI 状态互斥，不存在同时具有优势和劣势的内部状态。自由检定当前也允许对任意骰面使用优势/劣势；这属于通用掷骰工具行为，不应描述为 5E 对所有骰子的规则。

## 多次投掷

次数可选 1、2、3、4、5、10。每次独立生成日志：

```text
最终结果 = 选定骰值 + 基础加值 + 额外加值
```

优势/劣势时每一次投掷都会独立生成两个骰值后取高/低。新日志整体插入列表顶部。

## 日志

每条日志保存：

- 检定名称。
- 最终结果。
- 原始骰值、优势/劣势选择和加值明细。
- D20 最终骰值是否为 20 或 1 的显示标记。

日志仅存在于 `AdventurePage._logs` 内存列表中：

- 切换角色不会自动清空日志，因此同一页面实例中可能混合不同角色结果。
- 离开冒险一级页面会销毁日志。
- 清空操作不可撤销，但不影响角色数据。

如果未来持久化或分享日志，应额外保存角色 ID、角色显示名、时间和规则版本，且不能改变“只展示”的产品语义。

## 随机性

当前使用 Dart `Random()`，适合普通桌游娱乐，不声明密码学安全、可验证公平或跨设备可复现。多人联机若需要可审计骰子，必须另行设计服务端/共享种子协议。

## 示例

角色敏捷 16（修正 +3）、隐匿熟练、熟练加值 +2、临时额外加值 +1：

```text
隐匿总加值 = +3 +2 +1 = +6
骰面 14 → 展示结果 20
```

优势时骰面为 7 和 14：

```text
优[7, 14] → 14；14 + 6 = 20
```

应用只展示 20，不判断是否通过 DM 设置的 DC。

## 测试要求

- 骰子边界始终在 1～骰面。
- 优势取高、劣势取低、正常取第一值。
- 熟练加值只加一次。
- 先攻使用完整 `combat.initiative`，不再重复加敏捷。
- 非 D20 不显示自然 20/1 标记。
- 通用投掷和清空日志均不改变 `Character.toJson()`。
- 专用死亡豁免规则覆盖 2/9/10/19 边界、自然 1/20、三次上限、终局锁定和手工重置。
- 随机源应可控制后再编写确定性测试。
