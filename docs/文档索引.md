# DnD Toolkit 文档索引

本目录是项目的长期事实库，主要服务于后续开发和 AI 协作。根目录 `README.md` 面向最终用户，不承担完整架构和兼容契约说明。

开始任何开发任务时先阅读 [`../AGENTS.md`](../AGENTS.md)，再按任务选择文档：

## 文档状态约定

- `active`：当前有效，开发时应遵守。
- `planned`：已确认方向，但尚未实现。
- `deprecated`：保留历史信息，不应继续扩展。
- `TBD`：尚未决定，AI 不得擅自补全为既定事实。

当文档与代码不同：产品文档和 ADR 说明目标，代码与测试说明现状；应在任务中指出差异，而不是静默忽略其中之一。
