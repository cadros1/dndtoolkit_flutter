# 术语表

| 术语 | 项目内含义 |
| --- | --- |
| DnD Toolkit | 本 Flutter 应用的产品名 |
| 5E 2014 | 当前规则基线，即 D&D 第五版 2014 规则体系 |
| 5R / 5E 2024 | 计划兼容的 2024 修订规则；当前尚未实现 |
| 角色 | 一个 `Character` 根对象及其本地 JSON 文件 |
| 角色卡 | 角色数据在应用 UI 或专用 PDF 中的呈现 |
| 冒险操作台 | 跑团时查看和修改动态状态、进入检定中心的一级页面 |
| 检定 | 应用选择 d20 或自由骰、加上数值并展示结果的操作 |
| 基础加值 | 根据检定类型从角色数据计算的加值 |
| 额外加值 | 用户在检定中心临时输入的加值，不持久化 |
| 熟练加值 | `Profile.proficiencyBonus`，用于已熟练豁免和技能 |
| 画像 | `Profile.portraitBase64` 中的角色图片；不上传云端 |
| 本地主要副本 | 应用文档目录中的 `<Character.id>.json` |
| 云端备份 | 用户手动上传到 Supabase 或从中下载的角色副本 |
| 身份令牌 | UUID v4 bearer secret，同时用于标识和授权一个云端备份空间 |
| 同步中心 | 当前 UI 名称；实际语义是手动云端备份中心，不是实时同步 |
| RLS | Supabase/PostgreSQL Row Level Security，用请求头令牌隔离行 |
| `updatedAt` | 角色最近保存时间，用于上传冲突提示 |
| PascalCase JSON | 角色 JSON 使用 `CharacterName`、`UpdatedAt` 等字段命名风格 |
| 专用 PDF | 随应用分发的 `assets/Character.pdf`，唯一正式兼容模板 |
| 动态状态 | 当前 HP、临时 HP、当前生命骰、钱币、剩余法术位、死亡豁免等跑团状态 |
| 规则内容 | 职业、种族、背景、法术、专长或规则原文；本项目不内置 |
| LAN 同步 | 已废弃的局域网/WPF 互传实现，不属于当前产品 |
| 应用内更新 | 未来从提示跳转升级为下载、校验并引导安装的能力；尚未实现 |
| NPC 卡 | 已实现的可复用 NPC 静态资料模板；保存在独立的本地 DM 数据文件中 |
| NPC 分类 | 用户自行命名的 NPC 卡分组；当前每张卡只属于一个分类 |
| NPC 实例 | 从 NPC 卡复制到当前遭遇的独立运行时副本，模板后续变化不追溯影响实例 |
| 集群 | 共享一个先攻值的 NPC 实例集合，可以混合不同 NPC 卡创建的成员 |
| 当前遭遇 | 唯一活动 DM 遭遇，保存 NPC 实例、集群及动态生命值，不追踪当前轮次或当前行动者 |
| 遭遇预设 | 后续计划加入的可复用 NPC 数量、命名和集群配置，用于创建新的当前遭遇 |

## 中文术语与代码 key

| UI 中文 | Dart 字段/key |
| --- | --- |
| 力量、敏捷、体质、智力、感知、魅力 | `strength`, `dexterity`, `constitution`, `intelligence`, `wisdom`, `charisma` |
| 体操 | `acrobatics`；PDF 内部字段称“杂技” |
| 隐匿 | `stealth`；PDF 内部字段称“躲藏” |
| 察觉 | `perception` |
| 驯兽 | `animalHandling` |
| 巧手 | `sleightOfHand` |
| 法术豁免难度 | `spellSaveDC` |
| 法术攻击加值 | `spellAttackBonus` |
| 剩余法术位 | `remainSlots` |
| 总法术位 | `totalSlots` |

新增用户可见术语时优先沿用当前 UI；如需全局更名，应同时检查 UI、PDF 映射、测试和文档。
