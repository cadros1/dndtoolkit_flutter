# ADR-0006：AI 建卡使用客户端配置的外部服务

## 决策

AI 建卡由客户端直接调用用户配置的 DeepSeek 或 OpenAI 兼容 Chat Completions 服务。应用不提供代理后端、账户额度或共享密钥。具名配置元数据保存在普通偏好中，API Key 使用 Windows/Android 系统安全存储。

AI 只生成独立、可校验的草稿 DTO。本地白名单映射为新的普通 `Character`，不会直接反序列化远端 JSON、修改已有角色或改变角色持久化格式。

## 理由

- 用户可以选择自己的提供商、模型、费用与思考设置。
- 不增加项目自有服务器、账户、密钥托管和运维责任。
- 独立 DTO 将不可信远端数据与已被真实用户使用的角色 JSON 契约隔离。
- 空白建卡和所有现有核心能力继续离线可用。

## 后果

- 用户必须自行取得 API Key，并承担第三方条款、费用、可用性和数据处理政策。
- OpenAI 兼容服务对 JSON 模式和思考参数的支持不完全一致，必须通过连接测试和清晰错误处理暴露差异。
- 应用不能独立验证所有职业、种族、法术和专长内容；它只验证结构、确定性计算与属性来源。
- API Key、完整提示词、原始响应和思考内容不得进入日志、测试 fixture、角色文件或云端备份。
