# ADR-0004：不内置规则内容

## 背景

应用面向 5E 2014，同时希望兼容第三方扩展和玩家自制内容。内置职业、种族、法术、专长或规则原文会引入授权、版本、翻译和内容维护成本，也会把开放表单变成封闭构筑器。

## 决策

- 应用只提供数值计算、空白字段和用户自行输入的内容。
- 不内置职业、种族、背景、法术、专长或规则原文数据库。
- 字段尽量保持自由文本，不以官方列表限制用户输入。
- 允许实现属性修正、熟练、技能关联和骰子等明确计算。
- 中文术语以当前 UI 为准。
- 5R 兼容通过规则版本和计算/字段适配实现，不通过复制大量规则内容实现。

## 结果

- 与第三方和自制内容兼容。
- 降低规则内容授权和更新压力。
- 应用不能提供完整角色构筑校验或自动填充规则说明。
- AI 不得在未获得新决策与来源确认时加入大段规则文本或封闭枚举。
