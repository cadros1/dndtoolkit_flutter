# ADR-0005：PDF 模板是固定兼容契约

## 背景

PDF AcroForm 字段名缺乏跨模板标准。尝试凭相似名称兼容网络上的任意角色卡会造成静默错位和数据丢失。项目已经有一份作者基于网络流通版本自制的中文模板和严格映射代码。

## 决策

- 只保证兼容随应用分发的 `assets/Character.pdf`。
- 允许并要求该模板随 Windows/Android 应用分发，以保证导出功能可用。
- 字段映射以 `PdfDataService` 实际代码为准。
- PDF 导入创建新角色，不依赖 PDF 内不存在的项目 UUID。
- 新模板必须独立识别和映射，不能用模糊匹配改变现有模板含义。
- 仓库内建立脱敏 fixture 和双向契约测试。

## 结果

- 导入导出行为可预测，能围绕固定字段建立回归测试。
- 用户不能假设任意 5E PDF 都可导入。
- 模板字段与数据模型演进必须协同处理。
- PDF 当前是角色卡基线交换格式，不是所有冒险动态状态的完整快照。
